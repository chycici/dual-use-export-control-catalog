# 两用物项进出口许可证知识库

> 基于2026年度《两用物项和技术进出口许可证管理目录》PDF  
> 来源：中华人民共和国商务部/海关总署  
> 生成时间：2026-05-06  
> 数据版本：1.0

## 用途

当用户给你一个产品名称，你可以用这个知识库快速判断：

1. 这个产品是否**落入两用物项目录**（进口或出口）
2. 如果命中，**推荐HS编码**是多少
3. **监管条件**是什么
4. 有哪些**报关要求**

## 数据规模

| 类别 | 条目数 |
|------|-------|
| 出口管制条目 | 754 |
| 进口管制条目 | 152 |
| **合计** | **906** |

> **注：进口条目均无管制编码**，这是原目录本身的设计（进口管制无国际管制编码体系）。进口条目的 `管制编码` 字段为空属正常情况，不代表数据缺失。  
> **注：部分条目无参考HS编码**（约176条），同样来自原目录未列明，并非数据缺失。查询时如HS编码为空，仍需按目录描述判断是否落入管制范围。

## 如何查询

当用户询问某产品是否为两用物项时，运行以下命令：

```bash
python3 skills/dual-use-export-control-catalog/search.py "产品名称"
```

需要查看原文摘要时追加 `--detail`：

```bash
python3 skills/dual-use-export-control-catalog/search.py "产品名称" --detail
```

其他常用参数：

| 参数 | 说明 |
|------|------|
| `--type 出口` 或 `--type 进口` | 限定目录类型 |
| `--limit 5` | 限制返回条数（默认10） |
| `--detail` | 返回完整原文摘要和报关要求 |

支持直接按 HS 编码或管制编码查询：

```bash
python3 skills/dual-use-export-control-catalog/search.py "8479899955"    # HS编码
python3 skills/dual-use-export-control-catalog/search.py "1B101"         # 管制编码前缀
```

收到 JSON 结果后，按【标准答复格式】格式化输出。无需自己写搜索代码。

## 命中状态判断规则

search.py 输出的 `hit_status` 字段已经提供了判定结果，直接使用即可：

| 状态 | 触发条件 |
|------|---------|
| ✅ **命中** | score ≥ 80 — 产品名称/别名/行业叫法精确匹配 |
| ⚠️ **疑似命中** | score 40-79 — 关键词部分匹配，需结合技术参数复核 |
| ❌ **未命中** | total_hits = 0 — 无任何字段匹配 |

`results` 中每条记录包含 `match_reasons` 字段，说明命中原因，格式化回复时可以引用。

## 标准答复格式

当用户问某个产品是否在两用物项目录中时，按以下格式回复：

```
产品名称：xxx
目录类型：出口 / 进口 / 可能同时涉及
知识库结果：✅ 命中 / ⚠️ 疑似命中（需结合参数复核） / ❌ 未命中
推荐HS编码：xxxxxx（如目录列示；若为空则原目录未列明，仍需按描述判断）
对应管制编码：1Axxx / 1Bxxx / ...（出口部分有；进口条目无此字段）
监管条件：两用物项和技术（进口/出口）许可证
报关要求：
1. 按目录描述核对技术参数、用途、成分、型号
2. 如落入管制范围，依法办理相应两用物项许可证
3. 即使目录未列明海关商品编号，只要物项或技术落入目录描述仍应办理许可证
4. 最终监管要求以最新法律法规和海关审核为准
风险提示：如果只是名称接近但参数不清，建议要求提供规格书或技术参数进行逐项复核。
目录原文摘要：...（使用 --detail 获取，方便二次判读）
```

## 查询注意事项

1. **初筛为主**：本库适合做初筛/知识检索，不替代正式商品归类、出口管制判定或海关/商务主管部门最终审核
2. **参数敏感**：许多条目按技术参数/性能阈值/用途管制，同一个产品名会因参数不同而命中或不命中
3. **编码未列明仍要办**：目录说明明确写明：**即使未列明海关商品编号，只要物项或技术落入目录描述，仍应依法办理两用物项和技术许可证**
4. **免责说明**：search.py 输出中的 `note` 字段包含重要免责信息，格式化回复时应一并引用
